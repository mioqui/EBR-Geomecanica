# EBR Geomecánica

Aplicación web (PWA) para el trabajo geomecánico en campo. Funciona sin internet una vez instalada.

**Acceso:** https://mioqui.github.io/EBR-Geomecanica/

## Módulos
- **RMR:** evaluación RMR 89 con ajuste por orientación, tipo de roca y sostenimiento según la cartilla.
- **GSI:** tabla GSI de El Brocal para labores permanentes y temporales.
- **Mapeo:** registro de estructuras (tipo, Dip / Dip Direction, tramo, persistencia, rugosidad, relleno).
- **Historial:** registros guardados, exportación a Excel con fotos e **Indicación Geomecánica F-EBR-GM-01.02 en PDF A4** para imprimir y firmar.

## Datos
Las evaluaciones, fotos y mapeos se guardan solo en el dispositivo de cada usuario. Este repositorio contiene únicamente el código de la app.

## Instalar en el celular
- **Android (Chrome):** abrir el enlace → menú ⋮ → *Agregar a pantalla de inicio*.
- **iPhone (Safari):** abrir el enlace → Compartir → *Agregar a inicio*.

Al publicar una versión nueva, abrir la app con internet, cerrarla y volver a abrirla para que se actualice.
